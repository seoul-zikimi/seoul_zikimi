Made with AI

AI, 한계를 풀어주다

우리 팀엔 그래픽 담당이 없습니다. 부족한 제작 리소스는 AI로 보완하고, 개개인의 개발 규모를 AI로 증폭하고, 워크플로우 전반에 AI를 통합했습니다.

VARCO 3D · Image Studio

비주얼을 만들다

플레이어 캐릭터 3종과 애니메이션, 다섯 맵의 건축 재료 전부, 배경 소품, 커스터마이징 아이템, UI 아이콘까지. 게임 안의 3D 에셋은 전부 VARCO로 만들었습니다. 흰 배경 3/4뷰 이미지를 만들고 5K 폴리곤 메시로 뽑는 표준 설정을 정해 두고 수백 개를 찍어냈습니다.

VARCO Voice

플레이어의 목소리가 되다

"망치 갖다줘!", "고정 안됐어!", "완성했어!" — 현장에서 필요한 퀵챗 11종을 달팽이·거북이·소라게 목소리로 녹음했습니다. 채팅창을 열지 않아도 말이 통합니다.

Claude Code · VARCO MCP

생산성을 증폭시키다

Claude 프롬프트로 VARCO 3D 에셋을 생성하고, 다시 프롬프트로 수정해 맵에 배치하는 워크플로를 연결했습니다. Discord에 QA 봇을 두어 팀원이 올린 버그 리포트가 바로 수정 작업으로 이어지고, 모바일 포팅과 최적화까지 이 흐름 안에서 끝냈습니다.

Suno

맵마다 어울리는 BGM

광통교, 남산, 롯데월드, DDP, 경복궁 — 맵마다 분위기가 다른 BGM과 마감이 다가오면 바뀌는 다급한 버전, 결과 화면 곡까지 Suno로 만들었습니다.
