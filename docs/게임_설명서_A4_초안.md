# 건축레인저 : 서울 — A4 1페이지 설명서 틀 (초안)

> 대상: 게임을 처음 보는 유저 (심사위원·전시 관람객 포함)
> 원칙: 글보다 그림. 한 블록 = 한 메시지. 읽는 순서가 시선 흐름과 일치하게.

---

## 페이지 레이아웃 (세로 A4, 6블록)

```
┌──────────────────────────────────────────────────┐
│ ① 헤더  로고 + 한 줄 소개 + 인원/시간           │  ~10%
├──────────────────────────────────────────────────┤
│ ② 목표  "계획도랑 똑같이 지어라"  (그림 1장)     │  ~15%
├──────────────────────────────────────────────────┤
│ ③ 핵심 루프  5칸 아이콘 스트립                   │  ~25%
│    주문 → 운반 → 배치 → 망치질 → 채점           │
├────────────────────────┬─────────────────────────┤
│ ④ 조작표 (표)          │ ⑤ 꿀팁 3줄             │  ~30%
├────────────────────────┴─────────────────────────┤
│ ⑥ 모드 & 캐릭터 한 줄씩 + QR/홈페이지            │  ~20%
└──────────────────────────────────────────────────┘
```

## ① 헤더

- 로고 (뉴 로고.png)
- 한 줄 소개: **"무너진 서울, 등껍질 삼총사가 다시 짓는다!"**
- 스펙 뱃지: `1~4인 협동` · `2 vs 2 대결` · `한 판 5~10분` · `PC / 모바일`

## ② 목표 (이것만 알면 됨)

- 큰 문장 하나: **"휴대폰 속 완공 계획도와 똑같이 지으면 승리!"**
- 그림: 왼쪽 "계획도(휴대폰 화면)" → 오른쪽 "현장(반투명 정답 위에 블록 올린 모습)"
- 보조 문장: "반투명한 자리가 정답 위치예요. 그 위에 재료를 딱 맞춰 놓으세요."

## ③ 핵심 루프 — 5칸 아이콘 스트립

| 1. 주문 | 2. 운반 | 3. 배치 | 4. 망치질 | 5. 채점 |
|---|---|---|---|---|
| 휴대폰(Tab)에서 재료 카드 클릭 → 배송 구역에 떨어짐 | 좌클릭으로 집기 / G 꾹 → 친구에게 던지기 | 반투명 정답 위에 놓기 (R로 회전) | E 꾹 → 고정. **고정 안 하면 점수 X** | 완성도 % → 별 → 코인 |

- 각 칸 아래 스크린샷 or 아이콘 1개.
- 4번 칸은 빨간 강조(초보자 최다 실수 = 망치질 안 함).

## ④ 조작표 (PC 기본키)

| 동작 | 키 |
|---|---|
| 이동 / 달리기 / 점프 | W A S D / Shift / Space |
| 카메라 회전 / 줌 | 우클릭 드래그 / 휠 |
| 휴대폰(계획도·주문) | Tab |
| 집기 · 내려놓기 | 좌클릭 |
| 든 물건 회전 | R |
| 던지기 | G 꾹 |
| 공정(망치·페인트·물) | E 꾹 |
| 공정 취소 | Z 꾹 |
| 비계 설치(높이 올라가기) | Space 2번 연타 |
| 감정표현 | T |

> 모바일 빌드용이면 화면 버튼 그림으로 대체. 패드는 지면상 생략(설정에서 확인 안내).

## ⑤ 꿀팁 3줄 (초보자 실수 방지)

1. **놓기만 하면 0점.** E 꾹 눌러 망치질까지 해야 완성도에 들어가요.
2. **위층은 비계로.** 받쳐줄 게 없으면 못 놓아요. Space 연타로 비계 세우기.
3. **던져서 나르세요.** G 꾹 → 조준 → 떼면 발사. 혼자 들고 뛰는 것보다 훨씬 빨라요.

(대안 후보: "계획도는 마우스로 돌려볼 수 있어요", "Z 꾹으로 되돌리기", "날씨 확인 — 비·눈엔 미끄럽고 강풍엔 재료가 날아감")

## ⑥ 모드 & 캐릭터 & 링크

**모드 (한 줄씩)**
- 타임어택 협동 — 1~4명, 제한 시간 안에 완성도 최대한 높이기
- 2 vs 2 대결 — 같은 건물 먼저 100% 짓는 팀 승리, 아이템으로 방해
- 자유 건축 — 타이머·채점 없음, 내 작품은 기록책에 저장

**캐릭터 (아이콘 + 한 줄)**
- 달팽이 — 벽을 기어올라 비계 없이 위층 직행
- 거북이 — 무거운 걸 들어도 느려지지 않음
- 소라게 — 집게발 사거리 1칸 더 김

**하단**: 홈페이지 QR · 튜토리얼 "설정 → 튜토리얼 다시 보기" 안내 · 팀명/버전
