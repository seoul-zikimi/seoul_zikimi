# 🎠 롯데월드 맵 만드는 법 (기획자용)

일반 맵 만드는 법은 [MAP_ADD_GUIDE_기획자용.md](MAP_ADD_GUIDE_기획자용.md)에 있어요.
이 문서는 **롯데월드 전용 기믹(퍼레이드)** 과 맵 구성을 설명합니다.

> 💡 **원클릭 생성**: **Tools ▸ Map ▸ ★ 롯데월드 맵 생성 (실전)** 한 번이면
> 파츠 8종 + 정답(매직캐슬 91칸) + 배경(호수·섬·광장·퍼레이드 길) + 기믹 설정 + 카탈로그 등록까지 끝.
> (맵 카드가 없으면 에디터 로드 시 자동으로 1회 실행됩니다.)

---

## 1. 맵 콘셉트

석촌호수 **매직아일랜드** 위에 **매직캐슬**(91칸, 높이 9)을 짓는다.
- **광장(남쪽)**: 배송존·망치작업대·페인트작업대·플레이어 스폰
- **섬(북쪽)**: 건축 그리드(13×12×13)
- **퍼레이드 길**: 광장과 섬 **사이**를 동서로 가로지름 ← 이 길을 계속 건너야 한다

즉 재료를 받거나 가공하려면 반드시 퍼레이드 길을 왕복해야 하고,
퍼레이드가 지나가는 동안은 **타이밍을 재서 건너야** 한다. (남산의 돌풍 같은 '운반 제약' 포지션)

## 2. 퍼레이드 기믹 동작

- 건설 페이즈 중 **20~32초 랜덤 주기**로 "🎉 퍼레이드 지나갑니다!" 예고(3초).
- 예고부터 경로에 **점선 표시**(주황=예고, 핑크=진행 중)가 떠서 어디로 오는지 보인다.
- 알록달록 퍼레이드 카 **3대**가 서→동으로 행렬 통과(속도 4m/s, 간격 1.8초).
- **치이면**: 경로 밖으로 강하게 밀려나고(7m/s), 벗어난 순간 **스턴 2초 + 든 재료 드롭**.
- 서버는 페이즈만 동기화, 카 위치는 전 클라 동일 계산(트래픽 없음).

## 3. 수치 조정

**맵 카드(`Map_LotteWorld`)의 `Lotte Gimmicks` 칸에 꽂힌 `LotteGimmickConfig_LotteWorld` 에셋**에서 조정:

| 분류 | 항목 | 기본값 |
|---|---|---|
| 주기 | 최소~최대 간격 | 20~32초 |
| | 예고 시간 | 3초 |
| 행렬 | 카 수 | 3대 |
| | 속도 | 4 m/s |
| | 카 간격 | 1.8초 |
| 충돌 | 충돌 반경 | 1.4m |
| | 밀쳐내는 속도 | 7 m/s |
| | 스턴 | 2초 |

이 칸이 **비어 있으면 기믹이 완전히 꺼집니다** — 다른 맵에는 영향 없음.

## 4. 배경 프리팹에 놓을 마커

일반 맵 필수 5종(`Spot_GridManager` `Spot_PlayerSpawnPoint` `Spot_HammerStation` `Spot_PaintStation` `Spot_DeliveryZone`)에 **더해서**:

| 마커 이름 | 무엇 | 주의 |
|---|---|---|
| `Spot_ParadePoint0` ~ `N` | 퍼레이드 경로 웨이포인트(0번부터 순서대로 이음) | **2개 이상 필수.** 직선이 아니어도 됨(폴리라인) |

경로를 곡선으로 만들고 싶으면 웨이포인트를 더 촘촘히 추가하면 됩니다.

## 5. 파츠 구성 (id 21~28 — 다른 맵과 충돌 없음)

| 파츠 | footprint | 공정 | 개수 |
|---|---|---|---|
| 성 기반 | 5×1×5 | 고정(하중부재) | 1 |
| 성 본체 | 3×3×3 | 고정(하중부재) | 1 |
| 성 상단 | 3×1×3 | 없음 | 1 |
| 코너타워 | 1×4×1 | 고정 | 4 |
| 타워지붕(파랑) | 1×2×1 | 페인트 | 4 |
| 중앙 첨탑(파랑) | 1×3×1 | 페인트 | 1 |
| 정문 게이트 | 1×2×1 | 페인트 | 1 |
| 깃발 | 1×1×1 | 페인트 | 1 |

정답 총 **91칸** (튜토리얼 8칸 < 남산 71칸 < **롯데월드 91칸**), 제한시간 **8분**.

## 6. VARCO 모델 적용

그레이박스(색큐브)로도 플레이 가능. 진짜 모델은
`Assets/Prefabs/Map/3_LotteWorld/Models/`에 GLB를 넣고 **Tools ▸ Map ▸ ★ 롯데월드 VARCO 모델 적용** →
배경 소품이면 **★ 롯데월드 맵 생성** 재실행. 자세한 파일 이름·프롬프트는
[Models/README.md](../Prefabs/Map/3_LotteWorld/Models/README.md) 참고.

### 배경 앰비언트 연출 (2026-08 추가)

모델이 있으면 맵 생성 시 자동으로 붙는 순수 비주얼 연출(네트워크 동기화 없음, `LotteAmbientRides`):

- **자이로드롭**: `롯데_자이로기둥` + `롯데_자이로원반` 분리형이 있으면 원반이 기둥을 타고
  상승(7초) → 정지(3초) → 낙하(0.8초) → 휴식(5초)을 반복. 분리형이 없으면 구형 통짜 `롯데_자이로드롭` 폴백.
- **모노레일**: `롯데_모노레일`(링 궤도)이 섬을 한 바퀴 두르고, `롯데_모노레일열차`가 궤도를 따라 순환.
  링·열차엔 콜라이더가 없다(빔이 머리 위라 게임플레이 간섭 없음).
- **다리**: `롯데_다리`(난간+가로등)가 그레이박스 다리를 대체(보행 콜라이더는 기존 박스 유지),
  다리 중간 좌우에 `롯데_다리탑` 쌍둥이 성탑. 다리탑이 없으면 기존 코너타워 게이트 폴백.
- **원경**: 어드벤처돔(북)·청록 돔요새(동)·아파트 2단지(서북)·적갈색 타워(북)·벚나무 8그루(호안).

## 7. 확인하기

1. **Window ▸ General ▸ Test Runner ▸ EditMode ▸ Run All** — 맵 데이터 검사 통과 확인
2. 로비에서 "롯데월드" 선택 → 호스트 시작 → 주문 → 퍼레이드 예고 때 길 건너보기 → 치여보기(스턴+드롭 확인)
