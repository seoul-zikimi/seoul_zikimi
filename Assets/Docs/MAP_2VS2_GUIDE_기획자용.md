# ⚔️ 2vs2 전용 맵 만드는 법 (기획자용)

일반 맵 만드는 법은 [MAP_ADD_GUIDE_기획자용.md](MAP_ADD_GUIDE_기획자용.md)에 있어요.
이 문서는 **2vs2 대결용 맵**에만 해당하는 추가 규칙입니다.

---

## 1. 2vs2에서 맵이 어떻게 달라지나요?

| 항목 | 협동(타임어택) | 2vs2 |
|---|---|---|
| 건축 그리드 | 1개 | **가로로 2배** — 왼쪽 절반=팀A, 오른쪽 절반=팀B |
| 가운데 | 없음 | **투명벽** 자동 생성 (넘어갈 수 없고, 상대가 보임) |
| 작업대(망치·페인트) | 1세트 | **자동으로 반대편에도 1세트** 생김 |
| 제한 시간 | 맵 설정 | 7분 고정 |

⚠️ **그리드는 하나입니다.** 가로로 2배 늘어나 양 팀 구역을 모두 덮어요.
그래서 `Spot_GridManager`는 **한 개만** 두면 되고, 그 자리가 **팀A 구역의 시작(왼쪽 아래)** 이 됩니다.

---

## 2. 맵 크기 잡기

건축 영역 크기는 **맵 카드(`Map_이름`)의 Grid Size**에서 맵마다 정합니다. (1칸 = 1m)
비워두면 GameScene의 `GridManager` 값을 씁니다.

- 2vs2 전체 건축 영역 = **가로 2배** (팀A 폭 + 팀B 폭)
- 투명벽은 정확히 **가운데(팀A 구역이 끝나는 지점)** 에 섭니다
- 예: Grid Size가 16 × 8 × 16이면 전체는 **32 × 16칸**

배경은 이 32 × 16 영역을 감싸도록 만들고, **가운데 세로줄(투명벽 자리)은 반드시 비워주세요.**
구조물이 걸치면 상대 진영이 안 보여서 대결의 재미가 사라집니다.

---

## 3. 대칭으로 만들기 — 두 가지 방법

### 방법 A. 직접 대칭으로 제작 (권장)

1. 팀A 쪽 배경을 꾸민다
2. 그걸 복제해서 **가운데(투명벽) 기준으로 180° 회전**해 반대편에 놓는다
   - 좌우 뒤집기(미러)가 아니라 **회전(점대칭)** 입니다. 위아래가 반대로 놓여야 맞아요.
3. 배경 프리팹 루트에 **`VersusSymmetric`** 이라는 빈 오브젝트를 하나 넣는다
   → "이미 대칭으로 만든 맵"이라는 표시. 시스템이 배경을 건드리지 않습니다.

### 방법 B. 자동 복제에 맡기기 (임시)

`VersusSymmetric` 표시가 **없으면**, 시스템이 팀A 쪽 배경을 180° 복제해 반대편을 채웁니다.
빠르지만 가운데가 두꺼워지거나 구조물이 겹칠 수 있어서 **테스트용으로만** 쓰세요.

---

## 4. Spot 마커 놓기 (5종 전부 필수)

배경 프리팹 안에 빈 오브젝트를 만들고 이름을 아래처럼 정확히 지어주세요. **팀A 쪽에만 놓으면 됩니다.**

| 마커 이름 | 무엇 | 2vs2에서 |
|---|---|---|
| `Spot_GridManager` | 건축 그리드 시작점(왼쪽 아래) | 한 개만 — 그리드가 2배로 늘어 양쪽을 덮음 |
| `Spot_PaintStation` | 페인트통 작업대 | **반대편에도 자동 생성** |
| `Spot_HammerStation` | 망치 작업대 | **반대편에도 자동 생성** |
| `Spot_PlayerSpawnPoint` | 플레이어 시작 위치 | 팀B는 자동으로 자기 구역에서 시작 |
| `Spot_DeliveryZone` | 주문한 재료가 떨어지는 자리 | 팀별로 자기 구역에 떨어짐 |

💡 작업대는 **씬에 미리 둘 필요가 없어요.** 마커만 두면 그 자리에 생깁니다.
(프리팹이 없다면 **Tools ▸ Map ▸ 시스템 오브젝트 프리팹 만들기** 를 한 번 실행)

⚠️ 이름에 오타가 있으면 조용히 무시됩니다 — 아래 5번 자동 검사로 잡으세요.

---

## 5. 확인하기

### 자동 검사 (제일 먼저)

**Window ▸ General ▸ Test Runner ▸ EditMode ▸ Run All**

`MapAuthoringValidationTests`가 마커 5종 누락, 이름 오타, 배경 프리팹 미연결, 정답 누락을 잡아줍니다.
빨간 줄에 뜬 메시지대로 고치면 돼요.

### 눈으로 확인 (Play 없이)

1. Project에서 맵 카드(`Map_이름`) 선택
2. **Tools ▸ Test ▸ 2vs2 배경 미리보기**
   - 배경 + (필요시) 자동 복제 + 가운데 투명벽 + 팀 구역(파랑=A, 빨강=B) + 그리드 격자가 뜹니다
   - 볼 것: **좌우가 점대칭인가 / 가운데가 뚫려 있는가 / 격자가 양쪽으로 이어지는가**
3. **Tools ▸ Test ▸ 2vs2 미리보기 지우기** — 확인 후 정리 (**씬은 저장하지 마세요**)

맵을 아직 안 만들었는데 규칙만 보고 싶다면 **Tools ▸ Test ▸ 2vs2 더미 배경 미리보기** 를 쓰세요.
일부러 비대칭으로 만든 임시 블록으로 대칭이 어떻게 도는지 보여줍니다.

### 실제로 해보기

로비에서 방장이 주황색 **모드** 버튼을 눌러 `2vs2 대결`을 고르고 시작하면 됩니다.

---

## 자주 하는 실수

| 증상 | 원인 |
|---|---|
| 상대 진영이 안 보임 | 가운데(투명벽 자리)에 구조물이 걸침 |
| 반대편이 어색하게 겹침 | `VersusSymmetric` 없이 자동 복제된 것 → 직접 대칭 제작 |
| 작업대가 한쪽에만 있음 | `Spot_` 마커가 아니라 씬에 직접 둔 오브젝트라서 (마커로 옮기세요) |
| 망치·페인트통이 아예 안 보임 | 프리팹 미생성 → Tools ▸ Map ▸ 시스템 오브젝트 프리팹 만들기 |
| 재료가 엉뚱한 데 떨어짐 | `Spot_DeliveryZone` 없음 → 그리드 옆 기본 위치로 떨어짐 |
| 그리드가 한쪽만 있는 것 같음 | 정상입니다 — 그리드는 하나이고 2배로 늘어 양쪽을 덮습니다 |
