# 🗺️ 맵 추가 가이드 (기획자용)

새 맵을 게임에 넣는 방법이에요. **씬을 만들 필요 없고, 코드도 몰라도 돼요.**
버튼 몇 번이면 끝나요!

> 개발자용 상세 문서: [MAP_ADD_GUIDE.md](MAP_ADD_GUIDE.md)
> 블록·정답 그리는 법: [Grid/AUTHORING_GUIDE.md](Grid/AUTHORING_GUIDE.md)

---

## 맵이 뭐로 이루어져 있나요?

맵 하나 = **배경**(주변 풍경) + **정답 구조물**(따라 지을 건물) + **이름·썸네일**(로비 표시용)

이 재료들이 `Map_이름` 이라는 **맵 카드(에셋)** 하나에 담겨요.
로비에서 방장이 ◀ ▶ 로 맵 카드를 넘기며 고르면, 그 맵으로 게임이 시작돼요.

---

## 새 맵 만들기 — 5단계

### 1️⃣ 배경 모델 가져오기
- 배경용 3D 모델을 `Assets/Map/02_맵이름/` 폴더에 넣어요.
- ⚠️ **모델이 무거우면 게임이 뚝뚝 끊겨요!**
  넣은 뒤 **[메뉴] Tools ▸ Map ▸ Mesh Decimator**를 한 번 돌려주세요. (폴리곤 자동 다이어트)

### 2️⃣ 씬에 배경 꾸미기
- **GameScene**을 열고, 빈 오브젝트를 만들어 이름을 **`Background`**로 해요.
- 그 아래에 배경 모델들을 자유롭게 배치해요. (건축 그리드 자리는 비워두기!)
- ⚠️ **Background에는 "꾸미기용 배경"만!**
  PaintStation·HammerStation·GridManager·Grid·PlayerSpawnPoint 같은 건 **게임 시스템**이라
  Background에 넣지 않아요. 씬에 그대로 두면 어느 맵에서든 공용으로 재사용됩니다.

### 3️⃣ 맵으로 등록 (버튼 한 번)
- Hierarchy에서 `Background` 선택 → **[메뉴] Tools ▸ Map ▸ Extract Background To Map**
- 자동으로 처리돼요: 배경이 프리팹으로 저장되고 + 맵 카드가 생기고 + 게임 목록에 등록돼요.
- **Ctrl+S로 씬 저장** 꼭!

### 4️⃣ 맵 카드 꾸미기
- `Assets/Map/Maps/Map_이름.asset` 클릭 → Inspector에서:
  - **Display Name**: 로비에 보일 이름 (예: "청계천 광통교")
    ⚠️ 출시 후 바꾸면 유저 최고기록이 초기화된 것처럼 보여요. 신중히!
  - **Thumbnail**: 로비 "선택된 맵 이미지"에 뜰 그림
    (3️⃣ 때 자동으로 한 장 찍혀서 들어가요. 마음에 안 들면 직접 만든 이미지로 교체하거나,
    맵 카드 선택 후 **Tools ▸ Map ▸ Regenerate Map Thumbnail**로 다시 찍어요)
  - **Answers**: 이 맵에서 나올 정답들 (아래 5번에서 만든 걸 끌어다 넣기)
  - **Available Materials**: 이 맵에서 주문할 수 있는 재료들. 비워두면 카탈로그의 재료가 전부 나와요.
    (재료 목록 자체는 전역 카탈로그 그대로이고, 여기서 "이 맵에서 파는 것"만 골라주는 거예요)
  - **Grid Size**: 이 맵의 건축 영역 크기(가로 × 높이 × 세로, 칸). 맵마다 다르게 줄 수 있어요.
    비워두면(0, 0, 0) GameScene의 기본값을 씁니다. 2vs2에서는 가로가 자동으로 2배가 돼요.
    ⚠️ 정답 구조물이 이 범위 안에 들어가야 합니다.

### 4.5️⃣ 시스템 오브젝트 위치 정하기 (**5종 전부 필수**)
- 그리드·페인트대·망치대 위치가 맵마다 다르면, **배경 프리팹 안에 빈 오브젝트 마커**를 만들어요.
- 마커 이름 = `Spot_` + 씬 오브젝트 이름. 예:
  - `Spot_GridManager` — 그리드(건축 구역) 위치
  - `Spot_PaintStation` / `Spot_HammerStation` — 작업대 위치
  - `Spot_PlayerSpawnPoint` — 플레이어 시작 위치
  - `Spot_DeliveryZone` — 주문한 재료가 **떨어지는(착지) 지점**
- 💡 `Spot_DeliveryZone`은 끌어서 옮기면 노란 바닥 표시가 실시간으로 따라옵니다. 없으면 그리드 옆 기본 위치로 떨어져요.
  (예전에 쓰던 `DeliveryPoint`라는 이름은 더 이상 쓰지 않습니다.)
- 게임 시작 때 배경이 뜨면서, **씬에 있으면 그 자리로 옮기고 / 없으면 마커 자리에 새로 생깁니다.**
  즉 작업대는 씬에 미리 둘 필요 없이 **마커만 두면 돼요.** (프리팹은 `Assets/Resources/SystemObjects/`에 있고,
  없다면 **Tools ▸ Map ▸ 시스템 오브젝트 프리팹 만들기** 를 한 번 실행)
- 마커도 없고 씬에도 없으면 그 오브젝트는 아예 안 나옵니다(콘솔에 경고).
- 📌 **마커의 Y는 "발이 닿는 바닥 높이"입니다.** 작업대는 게임이 알아서 그 바닥 위에 올려놓아요.
  그러니 마커는 **땅에 딱 붙여 두세요** — "파묻힐까 봐" 0.3·0.5씩 손으로 올리면 이번엔 공중에 뜹니다.
  (지면이 0이 아닌 맵도 마찬가지: DDP 광장이면 `y = -4`, 남산 아랫동네면 `y = -2.5`)

### 5️⃣ 정답 구조물 넣기
- [AUTHORING_GUIDE.md](Grid/AUTHORING_GUIDE.md) §4대로 AnswerAuthoring 씬에서 정답을 그려서 내보내요.
- 나온 에셋을 복제해서 이름 바꾸고(예: `Answer_새맵_다리1`), 맵 카드의 **Answers**에 넣어요.
- 여러 개 넣으면 판마다 랜덤으로 하나가 나와요.
- ※ Answers를 비워두면 GameScene의 기본 정답 목록이 쓰여요.
- ⚠️ **맵이 2개 이상이면 각 맵 카드에 반드시 그 맵의 Answers를 넣어주세요.**
  비워두면 공용 목록으로 떨어져서, 튜토리얼 맵인데 광통교 정답이 나오는 식으로 섞일 수 있어요.
  (광통교 카드에는 광통교 정답이 이미 들어 있어요 — 새 맵도 똑같이 해주면 끝!)

## 2vs2 전용 맵 만들기

2vs2는 그리드가 가로로 2배가 되고 가운데에 투명벽이 서는 등 규칙이 달라요.
→ **[MAP_2VS2_GUIDE_기획자용.md](MAP_2VS2_GUIDE_기획자용.md)** 에 따로 정리해뒀습니다.

## 플레이 없이 확인하는 도구

| 하고 싶은 것 | 메뉴 |
|---|---|
| 맵 세팅이 제대로 됐는지 자동 검사 | **Window ▸ General ▸ Test Runner ▸ EditMode ▸ MapAuthoringValidationTests ▸ Run** |
| 2vs2 배경이 대칭인지, 가운데가 뚫렸는지 | **Tools ▸ Test ▸ 2vs2 배경 미리보기** (맵 카드 선택 후) / 정리는 **2vs2 미리보기 지우기** |
| 아이템 파티클·소리, 사거리(2칸), 배송 지점 | **Tools ▸ Test ▸ 샌드박스 테스트 씬** → Play (WASD=이동, 1~5·0·←→=아이템 FX) |

Test Runner는 "정답 안 넣음 / 배경 안 연결 / 마커 이름 오타" 같은 실수를 이름으로 알려줘요.
빨간 줄이 뜨면 그 메시지대로 고치면 됩니다.

> 자세한 테스트 방법은 [TEST_GUIDE.md](TEST_GUIDE.md) 참고.

## 확인하기

1. Play → 로비에서 방 만들기
2. 맵 이미지 옆 **◀ ▶** 로 새 맵 선택 (방장만 보여요. 맵이 2개 이상일 때만 떠요)
3. 게임 시작 → 새 배경이 뜨고, 그 맵의 정답이 나오면 성공! 🎉
4. 벽 뒤에 숨었을 때 벽이 반투명해지는지도 확인 (자동이에요)

## 자주 하는 실수

| 증상 | 원인 |
|---|---|
| 게임이 뚝뚝 끊김 | 1️⃣ Mesh Decimator 안 돌림 |
| 배경이 안 보임 | 3️⃣ 후 씬 저장 안 함 / 툴 실행 안 하고 씬에 그냥 둠 |
| 블록을 배경 위에 못 지음 | 배경이 그리드 자리를 침범함 |
| 로비에 ◀▶ 가 안 보임 | 맵이 1개뿐이거나, 방장이 아님 |
| 다른 맵의 정답이 나옴 | 5️⃣ 맵 카드 Answers가 비어 있음 → 공용 목록으로 폴백됨 |
