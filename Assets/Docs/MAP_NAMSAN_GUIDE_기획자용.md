# 🗼 남산타워 맵 만드는 법 (기획자용)

일반 맵 만드는 법은 [MAP_ADD_GUIDE_기획자용.md](MAP_ADD_GUIDE_기획자용.md)에 있어요.
이 문서는 **남산타워 전용 기믹(케이블카·엘리베이터·돌풍)** 을 켜는 방법입니다.

> 💡 **실전 남산타워 맵**은 **Tools ▸ Map ▸ ★ 남산타워 맵 생성 (실전)** 원클릭으로 만들어집니다
> (배경·파츠·정답·기믹 설정·카탈로그 등록까지). VARCO 모델을 갈아끼울 땐
> `Models/` 폴더에 GLB를 넣고 **★ 남산 VARCO 모델 적용** → **★ 남산타워 맵 생성** 순서로 재실행하세요.

---

## 1. 기믹은 어떻게 켜나요?

**맵 카드(`Map_이름`)의 `Namsan Gimmicks` 칸에 설정 파일을 꽂으면 켜집니다.**

1. Project 창에서 우클릭 ▸ Create ▸ Jobsnail ▸ **Namsan Gimmick Config**
2. 만들어진 에셋의 인스펙터에서 수치를 조정 (기획서의 [수정가능하게] 값 전부 여기 있음)
3. 맵 카드의 **Namsan Gimmicks** 칸에 이 에셋을 드래그

이 칸이 **비어 있으면 기믹이 완전히 꺼집니다** — 일반 맵은 아무것도 안 해도 돼요.

## 2. 설정 에셋에서 조정하는 수치

| 분류 | 항목 | 기본값(기획 확정치) |
|---|---|---|
| 케이블카 | 곤돌라 수 | 3대 |
| | 싣고 올라오는 시간 | 5초 |
| | 다음 곤돌라 도착 간격 | 3초 |
| | 수령 후 문 닫힘 | 2초 |
| | 미수령 이탈(재료 삭제) | 20초 |
| 엘리베이터 | 전망대 판정 y 범위 | 11~13 |
| 돌풍 | 주기 | 12~18초 랜덤 |
| | 예고 | 3초 |
| | 부는 시간 | 3초 |
| | 약풍 시작 높이 / 밀림 | y10 / 2칸 |
| | 강풍 시작 높이 / 밀림 | y15 / 4칸 |
| | 추락 스턴 | 2초 |

## 3. 배경 프리팹에 놓을 마커

일반 맵 마커에 **더해서** 아래 4종을 배치합니다. (전부 빈 오브젝트, 이름 정확히!)

| 마커 이름 | 무엇 | 주의 |
|---|---|---|
| `Spot_CableCarStation` | 케이블카 하차장 — 재료 받는 곳 | **필수.** 건축 구역 가장자리 추천 |
| `Spot_CableCarOrigin` | 산 아래 출발점 — 와이어 반대쪽 끝 | 하차장보다 낮게 두면 와이어가 기울어져 예쁨 |
| `Spot_ElevatorLower` | 데크 밑 건물의 엘리베이터 문 | 케이블카 하차장에서 가까운 곳 추천(동선 압축) |
| `Spot_ElevatorUpper` | 전망대층 문 | **도착해서 설 바닥이 있는 위치에!** (공중이면 떨어짐) |

⚠️ 남산 기믹 맵은 `Spot_DeliveryZone`이 **필요 없습니다** (케이블카가 대신). 대신
`Spot_CableCarStation`이 없으면 자동 검사가 실패해요.

## 4. 기믹별 동작 요약 (뭐가 자동인가)

- **케이블카**: 주문 UI는 그대로. 주문하면 하늘 배송 대신 곤돌라가 실어 옴.
  열린 곤돌라의 재료는 **좌클릭으로 집기** (바닥 재료와 동일). 곤돌라 위에 남은 초 표시.
  20초 미수령 시 재료를 싣고 떠나며 삭제 — 같은 재료 재주문 가능(비용 없음).
- **엘리베이터**: 전망대 판정 범위(y)의 정답 셀이 전부 **배치+공정 완료**되면 자동 개통.
  개통 연출(토스트+문 색 변화)이 양쪽 문에서 동시에 나옴. 문 앞에서 **E키**로 반대편 순간이동.
- **돌풍**: "⚠ 돌풍 주의!" 예고 3초 후 수평으로 붐. 그리드 상공의 **화살표가 풍향**.
  고정된 블록·벽 **뒤에 숨거나 기대면** 안 밀림. 밀려서 떨어지면 착지 시 스턴 + 든 재료 떨굼.
  비계(Space 연타)는 기존 그대로 — 바람 심한 구간에서 발판으로 쓰세요.

## 5. 확인하기

1. **Window ▸ General ▸ Test Runner ▸ EditMode ▸ Run All**
   — 맵 데이터 검사(마커 오타·필수 마커)와 기믹 수치 검사가 같이 돕니다.
2. 로비에서 맵 선택 → 호스트 시작 → 주문 → 곤돌라 확인 → 타워 짓기 → 개통 → 돌풍 확인.

## 6. 아직 없는 것 (개발팀에 요청)

- 돌풍/케이블카 전용 **사운드** (현재 무음 — GridSoundBridge에 이름 추가 필요)
- 바람 **파티클 이펙트** (현재는 풍향 화살표만)
- 2vs2 대응 (남산은 협동 전용으로 개발됨)
