# 테스트 가이드

무엇을 확인하고 싶은지에 따라 방법이 다릅니다. 위에서부터 싸고 빠른 순서예요.

| 확인하고 싶은 것 | 방법 |
|---|---|
| 맵 데이터가 제대로 세팅됐는지 | 1. EditMode 테스트 |
| 점수·붕괴·사거리·배송 좌표 같은 규칙 | 1. EditMode 테스트 |
| 아이템 파티클·소리, 사거리 감각, 주문→배송 낙하 | 2. 샌드박스 씬 |
| 2vs2 배경이 대칭인지, 가운데가 뚫렸는지 | 3. 2vs2 배경 미리보기 |
| 실제 멀티 플레이 흐름(팀·타이머·승패) | 4. 실게임 |

## 1. EditMode 테스트 (Test Runner)

코드 규칙과 맵 데이터를 자동으로 검사합니다. 플레이할 필요 없이 몇 초면 끝나요.

**에디터에서:** `Window ▸ General ▸ Test Runner ▸ EditMode ▸ Run All`

**터미널에서(유니티를 닫아야 함 — 같은 프로젝트를 두 번 열 수 없습니다):**

```bash
"C:/Program Files/Unity/Hub/Editor/6000.3.11f1/Editor/Unity.exe" \
  -batchmode -nographics -projectPath "C:/Users/swu/Documents/GitHub/seoul_zikimi" \
  -runTests -testPlatform EditMode \
  -testResults "결과.xml" -logFile "로그.txt"
```

종료 코드 0이면 전부 통과, 2면 실패한 테스트가 있다는 뜻이고 결과 xml에 이유가 한글로 적힙니다.

**무엇을 잡아주나**

- `MapAuthoringValidationTests` — 기획자용. 배경 프리팹 미연결, 맵이 2개 이상인데 Answers가 빔,
  `Spot_` 마커 이름 오타, 배경 안에 게임 시스템 오브젝트가 섞임, 배송 지점 이중 지정
- `ReachAndDeliveryTests` — 사거리(2칸)가 큰 블록의 가장자리 기준으로 재지는지, 배송 좌표가 잘려나가지 않는지
- 그 외 그리드/점수/붕괴/공정, 날씨·낮밤, 게임플레이 프레임워크 테스트

## 2. 샌드박스 씬 — `Assets/Scenes/SandboxTest.unity`

네트워크 로비 없이 Play만 누르면 자동으로 호스트가 시작됩니다.
없거나 구성이 빠졌으면 `Tools ▸ Test ▸ 샌드박스 테스트 씬` 메뉴로 만들거나 보강하세요(이미 꾸며둔 건 안 건드립니다).

| 조작 | 확인 내용 |
|---|---|
| `WASD` | 테스트 플레이어 이동. 블록이 **초록**이면 사거리 안, **빨강**이면 밖. 9×9 블록도 옆에 서면 초록이어야 정상 |
| `1` `2` `3` `4` | 아이템 등장 / 획득 / 발동 / 소멸 파티클과 소리 |
| `5` `0` | 아이템 구슬 놓기 / 전부 지우기 |
| `←` `→` | 아이템 종류 바꾸기(색·이름이 콘솔에 표시) |
| `V` | 2vs2 대칭 미리보기 켜기/끄기 — 더미 배경 + 180° 미러 + 가운데 투명벽 + 팀 구역(파랑=A, 빨강=B) |
| 우상단 주문 HUD | 재료 주문 → 하늘에서 날아와 `Spot_DeliveryZone` 자리에 낙하 |
| `Spot_DeliveryZone` 끌기 | 노란 바닥 마커가 실시간으로 따라옴 = 실제 착지 지점 |

주문할 때 콘솔에 `[Depot] 배송 지점 = (좌표) (출처: ...)`가 찍힙니다. 출처가 `Spot_DeliveryZone`이 아니면
마커를 못 찾고 폴백으로 떨어진 것이니 이름과 활성 상태를 확인하세요.

## 3. 2vs2 배경 미리보기

Play 없이 씬 뷰에서 대칭 상태를 봅니다.

1. Project에서 맵 카드(`Map_이름`)를 선택
2. `Tools ▸ Test ▸ 2vs2 배경 미리보기` — 배경 + (전용 대칭 맵이 아니면) 180° 미러 복제 + 가운데 투명벽 + 팀 구역 표시가 생성
   - 맵이 아직 없거나 규칙만 보고 싶으면 **`Tools ▸ Test ▸ 2vs2 더미 배경 미리보기`** — 일부러 비대칭으로 만든
     임시 블록과 `Spot_` 마커 5종(노란 핀)으로 대칭이 제대로 도는지 확인할 수 있습니다
3. 가운데가 구조물로 막혀 있지 않은지, 좌우가 대칭인지 확인
4. `Tools ▸ Test ▸ 2vs2 미리보기 지우기` — **씬은 저장하지 마세요**

전용 대칭 맵(배경 루트에 `VersusSymmetric` 빈 오브젝트)이면 복제를 건너뛴다고 콘솔에 알려줍니다.

## 4. 실게임 확인

BootstrapScene부터 시작해야 합니다(SoundManager 등이 거기서 생성됨).

- **협동/타임어택**: 방 만들기 → 게임 시작 → 주문·배치·공정·채점
- **2vs2**: 로비에서 방장이 주황색 `모드` 버튼으로 `2vs2 대결` 선택 → 4명 접속(에디터 + 빌드 조합)
  - 그리드가 좌우 2배로 늘고 가운데 투명벽이 서는지
  - 상대 구역에는 못 짓는지, 타이머 아래 `우리 % : 상대 %`가 갱신되는지
  - 30초쯤 지나면 색 구슬(아이템)이 스폰되고, 다가가면 자동 획득 → **도구를 들지 않은 상태에서 `E`** 로 사용
  - 속도 버프/디버프는 15초간 이동속도가 눈에 띄게 달라짐
  - 7분 종료 또는 조기 종료(=항복) 시 승/패/무 결과 패널

## 자주 보는 로그

| 로그 | 뜻 |
|---|---|
| `[Depot] 배송 지점 = ...` | 주문 시 실제 착지 좌표와 그 출처 |
| `[Depot] Spot_DeliveryZone 연결 — ...` | 배송 마커를 찾았다는 뜻 |
| `[MapLoader] 맵 마커 적용: ...` | `Spot_` 마커대로 시스템 오브젝트가 이동함 |
| `[MapLoader] Spot 대상이 씬에 없음: ...` | 마커 이름이 씬 오브젝트 이름과 안 맞음(오타) |
| `[MapLoader] 2vs2 배경 임시 대칭 복제` | 전용 대칭 맵이 아니라 자동 복제로 때움 |
| `[Item] 효과 미구현(소비됨): ...` | 아직 연결 안 된 아이템 효과(지진·날씨·안개 등) |
