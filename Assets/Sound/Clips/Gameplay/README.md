# 아이템·날씨·맵 사운드 클립 (17종)

이 폴더에 아래 파일명으로 클립을 넣고 **Tools ▸ Sound ▸ 아이템·날씨·맵 사운드 연결** 메뉴를 누르면
SoundLibrary에 자동 연결됩니다. 확장자는 `.wav` `.mp3` `.ogg` 아무거나. 일부만 넣어도 됩니다 —
없는 항목은 건너뛰고, 나중에 채운 뒤 메뉴만 다시 누르면 됩니다.

연결 전 동작: 아이템 계열은 기존 코드 합성음(뾰롱/펑/스윕)이 그대로 나고,
지진은 착지음 폴백, 날씨 루프·수문·퍼레이드·미끄덩은 무음입니다.

## A. 아이템 공통
| 파일명 | 소리 | 비고 |
|---|---|---|
| `Item_Box_Spawn` | 상자 나올 때 뾰롱 | 원샷, 3D(상자 위치) |
| `Item_Pickup` | 아이템 먹을 때 뾰롱 | 원샷, 3D |
| `Item_Use` | 발동 공통 스윕 | 전용음 없는 종류(우산 등)의 폴백 |

## B. 아이템 종류별 발동음 (시전자·당한 사람 모두 들림)
| 파일명 | 소리 | 비고 |
|---|---|---|
| `Item_Cannon_Fire` | 대포 펑~ | 발사 순간, 3D(시전자 위치). 착탄음은 별도(LandObject) |
| `Item_Earthquake` | 쿠르릉 돌 구르는 소리 | 3D(맞은 팀 진영 중앙) |
| `Item_Order_Hack` | 해킹 삐리릭 오류음 | 2D(거리 무관 전원) |
| `Item_Slowdown` | 하강음 (띠로리, 8bit 느낌) | 공정/이동속도 저하 공용, 2D |
| `Item_Speedup` | 상승음 (저하의 반대 느낌) | 공정/이동속도 상승 공용, 2D |
| `Item_Fog` | 연막탄 피유융 바람소리 | 2D |

## C. 날씨
| 파일명 | 소리 | 비고 |
|---|---|---|
| `Weather_Rain_Loop` | 빗소리 | **루프** — 끊김 없이 이어지게 제작 |
| `Weather_Wind_Loop` | 강풍 바람소리 | **루프** |
| `Weather_Typhoon_Loop` | 비+바람 태풍 | **루프** — 클립 하나에 믹스 |
| `Weather_Slip` | 미끄덩 킹받는 소리 | 원샷, 미끄러진 본인에게만 |

세션 날씨든 아이템으로 맞은 임시 날씨든 같은 루프가 쓰입니다(내 화면 기준 자동 전환).

## D. 맵 기믹
| 파일명 | 소리 | 비고 |
|---|---|---|
| `Ddp_Flood_Warning` | 수문 개방 경보 | 원샷, 예고 토스트와 동시 |
| `Ddp_Flood_Loop` | 물 콸콸 | **루프**, 3D — 수로에 가까울수록 크게 |
| `Lotte_Parade_Fanfare` | 퍼레이드 예고 팡파레 | 원샷 |
| `Lotte_Parade_Music` | 퍼레이드 행진곡 | **루프**, 3D — 선두 카를 따라다님 |

루프 클립은 시작·끝이 자연스럽게 이어지는(심리스) 소스여야 합니다. 페이드 인/아웃은 코드가 처리합니다(0.6초).
