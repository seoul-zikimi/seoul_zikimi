# 감정표현 아이콘 넣는 곳

감정표현 말풍선 **왼쪽에 붙는 작은 아이콘(이모티콘)** 이미지 폴더입니다.
`EmoteDefs.All[i].IconName` 과 **같은 이름의 PNG**를 여기 넣으면 해당 대사에 자동으로 붙습니다.
(코드 수정 불필요. 파일이 없어도 에러 아님 — 아래 우선순위대로 동작.)

## 우선순위

1. 이 폴더의 PNG (`Resources.Load`)
2. 없으면 [EmoteIconArt.cs](../../../Player/Scripts/EmoteIconArt.cs) 의 **임시 아트(코드 생성)**
3. 그것도 없으면 아이콘 없이 대사만

| 파일 이름 (확장자 제외) | 붙는 대사 | 현재 상태 |
|---|---|---|
| `Emote_Hammer` | 망치 갖다줘! / 망치질 필요해! | 임시 아트(코드 생성) — PNG 넣으면 대체됨 |

## 규격

- **정사각형 PNG**(권장 128x128 또는 256x256), 배경 투명.
- 반투명 검정 말풍선 위에 얹히므로 **밝고 진한 톤**이 잘 보입니다.
- 임포트 설정은 기본값 그대로 두면 됩니다(런타임에 스프라이트로 변환).

## 아이콘 추가하는 법

1. PNG를 이 폴더에 넣는다.
2. [EmoteDefs.cs](../../../Player/Scripts/EmoteDefs.cs) 의 해당 `new Def(...)` **세 번째 인자**에 파일 이름을 적는다.
3. 끝. (휠 UI·발동 로직은 손댈 것 없음)

> 보이스는 별도 폴더: [Resources/Voices/Emotes/](../../Voices/Emotes/README.md)
