🗺️ 맵 기획 그리드 툴 — 사용 설명서

피그마 대신 쓰는 블럭 설계도면 툴. tools/map-planner.html 더블클릭으로 실행.

1. 전체 흐름

맵 이름·셀 크기 설정→ 파츠 등록 (색·이미지·메모)→ 시트에 도면 그리기→ 🖼️ PNG로 기획서 첨부→ 📦 바르코 핸드오프로 에셋 생성

2. 상단 바

항목설명
맵 이름내보내는 이미지 제목과 파일명에 사용됨
셀 크기(m)1칸의 실제 크기. 좌표 표시와 실측 크기 계산에 반영 (게임 기준: 1칸 = 1m)
↩ 실행취소 / ↪ 다시실행Ctrl+Z / Ctrl+Y. 그리기·삭제 등 모든 편집에 적용

3. 시트 (층 / 뷰)

시트 하나 = 도면 한 장. 층별 평면도(1층, 2층…)나 정면도·측면도를 각각 시트로 만들어 관리한다.

  • ＋ 새 시트 추가 (이름·가로/세로 칸수 지정, 실측 크기 미리보기)
  • 더블클릭 — 이름/크기 수정. 크기를 줄이면 밖으로 나간 부분은 잘림 (좌상단 기준 유지)
  • ⧉ 복제 — 아래층 도면을 복사해 위층 그릴 때 유용
  • ✕ 삭제 — 마지막 남은 시트 1개는 삭제 불가

층별 시트 이름을 "1층", "2층"처럼 지어두면 나중에 유니티 자동 배치(정답 데이터 변환)로 연결하기 좋다.

4. 파츠

도면에 칠할 재료 목록. 색깔로 구분되며 시트별 사용 칸수가 실시간 표시된다.

  • ＋ 파츠 추가 / 더블클릭 수정 / ✕ 삭제 (배치된 셀도 함께 지워짐)
  • 공정 태그 ★ — 이 파츠에 필요한 공정을 태그로 선택 (기본: 망치질·페인트칠, 중복 선택 가능). ＋ 태그 추가로 새 공정(예: 자르기)을 만들 수 있고, 추가한 태그는 우클릭으로 삭제. 공정이 하나라도 있으면 팔레트에 ★ 표시(마우스 올리면 목록), PNG 범례에는 태그 이름이 그대로 나옴
  • 메모 — 크기·비율 등 (예: 4×4×6m). PNG 범례와 바르코 핸드오프에 포함
  • 레퍼런스 이미지 — 클릭해서 선택, 드래그, 또는 Ctrl+V 붙여넣기. 자동으로 축소 저장되고 팔레트에 썸네일 표시
  • VARCO 프롬프트 — 직접 적어도 되고, 비워두면 클로드가 레퍼런스+메모 보고 자동 생성

5. 그리기 도구

도구키설명

🪣 채우기G같은 색으로 이어진 영역을 한 번에 채움

  • E 또는 팔레트의 "지우개" = 지우개 선택
  • 1~9 = 파츠 빠른 선택
  • Ctrl+휠 또는 좌측 줌 슬라이더 = 확대/축소
  • 격자는 5칸마다 굵은 선 + 좌표 숫자. 하단 상태바에 마우스 위치의 칸/미터 좌표 표시

6. 저장 방식 (중요)

작업 내용은 브라우저 localStorage에 자동저장된다 (하단에 "자동저장됨" 표시). 같은 PC·같은 브라우저로 다시 열면 이어서 작업 가능.

단, 브라우저 데이터를 삭제하면 날아간다. 맵 하나 끝낼 때마다 💾 저장(JSON)으로 파일 백업을 남길 것. 내보낸 파일은 전부 다운로드 폴더에 떨어진다.

7. 바르코 연동 (에셋 생성 자동화)

  1. 파츠마다 레퍼런스 이미지와 메모를 채워둔다
  2. 📦 바르코 핸드오프 → 맵이름.varco.json 다운로드
  3. 바르코에서 커스텀 워크플로우 창을 하나 열어둔다
  4. 클로드 코드에 그 JSON을 주면서 "바르코 돌려줘" → 클로드가 파츠별 묘사 프롬프트 작성 + 이미지 업로드 + 3D 생성 실행까지 자동 진행

HTML 툴 자체에는 AI가 없다. 툴은 데이터 포장(JSON)까지만 하고, 프롬프트 생성과 바르코 실행은 클로드 코드가 담당하는 구조.
