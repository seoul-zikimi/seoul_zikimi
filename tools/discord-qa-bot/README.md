# 디스코드 QA 자동 수정 봇

QA 포럼에 글이 올라오면 → Claude Code가 `origin/main` 최신 기준으로 분석해 **간략한 수정 계획**을 스레드에 답글로 올림 → 팀원이 ✅ 누르면 **새 브랜치에서 수정 → 커밋 → 푸시 → PR 생성** → 결과 보고.

## 슬래시 명령어

- `/callclaude` — 작동 시작 (밀린 글 스캔 + 새 글 자동 처리 + ✅ 반응 처리)
- `/stopclaude` — 일시정지 (하던 작업 하나는 마저 끝냄)
- `/qastatus` — 현황 보기
- `/askclaude [note]` — **그 글 안에서** 입력하면 그 글만 다시 분석 (완료된 글에 추가 요청할 때. 일시정지 중에도 동작. `note`에 시킬 내용 적으면 반영)

봇 프로세스는 켜져 있어야 명령어를 받음. 프로세스 시작 직후에는 마지막 상태를 기억함 (첫 실행은 일시정지 상태).

⚠️ 명령어가 안 보이면: 봇 초대 URL에서 Scopes에 `bot` + `applications.commands` 둘 다 체크해서 다시 초대 (봇 추방 필요 없음, URL만 다시 열어 승인).

## 동작 흐름

1. 봇이 QA 포럼 새 글 감지 (시작 시 기존 미처리 글도 스캔)
2. 글 제목·본문·스레드 대화·첨부 스크린샷을 모아 `claude -p` (읽기 전용)로 수정 계획 생성
   - 분석·수정은 **봇 전용 작업 폴더**(git worktree, 레포 옆 `seoul_zikimi-qa-workspace`)에서 함 — 사용자의 작업 폴더는 안 건드림. 봇 돌아가는 중에도 평소처럼 작업 가능.
3. 스레드에 계획 답글 + ✅/❌ 이모지
4. 팀원이 ✅ → `origin/main`에서 `qa/issue-<글ID>` 브랜치 생성 → 수정 → 커밋 → 푸시 → PR 자동 생성 → 스레드에 브랜치·PR 링크 보고
5. ❌ → 건너뜀
6. 포럼에 `대기`/`수정중`/`완료` 태그가 있으면 자동 갱신 (없어도 동작함)

PR 자동 생성에는 `gh` CLI 로그인 필요 (`gh auth login`). 없거나 실패해도 브랜치 푸시까지는 됨.

## 준비 (1회)

1. https://discord.com/developers/applications → **New Application**
2. **Bot** 탭 → **Reset Token** → 토큰 복사
3. 같은 Bot 탭에서 **MESSAGE CONTENT INTENT** 켜기 (필수!)
4. **OAuth2 → URL 생성기** → 범위: `bot` → 봇 권한:
   - 채널 보기, 메시지 보내기, 스레드에서 메시지 보내기
   - 메시지 기록 보기, 반응 추가하기, 스레드 관리
   → 생성된 URL 열어서 봇을 서버에 초대
5. 디스코드 설정 → 고급 → **개발자 모드** 켜기 → QA 포럼 채널 우클릭 → **ID 복사**
6. 이 폴더에서:
   ```
   copy .env.example .env
   ```
   `.env` 열어서 토큰과 채널 ID 채우기 (**주의: .env.example 말고 .env에!** .env는 깃에 안 올라감)
7. (선택) 포럼 채널 편집 → 태그 추가:
   - `공지` — 이 태그 붙은 글은 봇이 완전히 무시
   - `미해결` — 붙이는 순간(또는 스캔 때) 처리 완료된 글도 다시 분석
   - `해결` — 수정 완료 시 봇이 자동으로 붙임 (없으면 `완료` 사용)
   - `대기`, `수정중` — 봇이 진행 상태 표시용으로 사용
   봇은 상태 태그만 교체하고 멤버가 붙인 분류 태그는 보존함.

## 실행

```
cd tools\discord-qa-bot
npm install
npm start
```

컴퓨터가 켜져 있고 이 프로세스가 살아 있는 동안 동작함.
백그라운드 상시 실행을 원하면 pm2 추천:

```
npm install -g pm2
pm2 start index.js --name qa-bot
pm2 save
```

## 참고

- 처리 기록은 `data/state.json`에 저장됨. 특정 글을 다시 처리하고 싶으면 해당 항목 삭제 후 봇 재시작.
- 수정 단계에서 Claude에게 허용된 도구는 파일 읽기/수정뿐 (git·Bash 실행 불가 — 커밋·푸시는 봇 스크립트가 직접 함).
- 시간 제한: 계획 10분, 수정 30분.
- 최초 ✅ 처리 때 봇 작업 폴더(worktree) 생성으로 몇 분 걸릴 수 있음.
